# ARX 真机目标遮挡与腕部 RGB-D 接力（2026-10-07）

基线为 `cd1686d`。所有实际机械臂动作在 dodo 本机的 gateway 执行，VLA 使用本机 `127.0.0.1:5583`；SSH 用于部署和查看实验记录。

## 修改

- 目标不可见、标签深度不足或跟踪不连续，返回 `unknown` 和空值。依赖缺失特征的 critic 规则不触发，成功条件和重入审核不能通过；相机身份、时间戳、设备或程序错误仍按原错误处理。
- 短暂失去观测时停止发送新动作，仅重新读取同步传感器。恢复观测后继续同一计划；两秒内未恢复则记录 `OBSERVATION_UNAVAILABLE`，不记作任务失败、不直接失能。
- 前置与右腕相机在三个不同新帧中测得同一粉色目标后，允许右腕接力。接力仍要求当前 RGB、毫米深度、关节 FK 和已冻结的腕部安装变换。
- 初始空夹爪期间要求目标位置连续；拒绝遮挡时冒出的其他粉色区域。标签至少有 12 个有效深度像素，且有效深度覆盖至少 80% 标签，才可参与测距或跨相机身份审核。临时缺帧不清除已确认的腕部身份，不复用旧深度。
- 空夹爪低电流接近时更新各相机的抬升基线；夹持时冻结基线。换观测源或缺帧会清空连续成功帧计数，避免视角偏移计作抬升。
- commissioning 可明确启用 `--resume-vla-once`：bundle 的预抓取完成并由真机观测验证后，执行重入审核，再执行一个 VLA 动作块。全部工具序列在第一条命令前核对。

## 配置与标定范围

最新两阶段候选配置为 `hardware-wrist-observer.json`、`grasp-config-wrist.json`、`bundle-wrist-refine.json`，输入冻结位于 `frozen-refine/`。其余 `frozen*` 目录记录此前各轮执行身份，不能搭配最新版 provider 直接部署。

右腕安装变换在 `right-wrist-mount.json`，可通过 `scripts/deployment/calibrate_arx_wrist_from_snapshots.py` 从留存的原始 RGB-D/FK 样本复现。使用首次空夹爪接近的前 60 步拟合，之后 61–100 步作时间上分离的验证；64 个拟合样本、40 个验证样本，验证 RMS 6.17 mm、最大 10.19 mm。

**这是一轮空夹爪接近过程中静止粉色标签的点配准，尚不等同于独立多姿态标定板手眼标定。** 同一颜色标签的曲面和 FK 误差仍会影响三维位置。它用于本次有人看护的预抓取 commissioning；尚未验证实际夹持与抬升阶段的精度。

保留原控制器关节限位、关节步长与实测到位要求。右夹爪 `+0.9` 夹紧预载保持不变。该次几何提案仅以可见标签作试管表面代理；TCP 点云净空不能证明全机械臂和夹爪无碰撞。

第 06 轮终点跨视角标签位置差为 15.25 mm，预抓取距离为 37.04 mm；原 15 mm 位置差审核拒绝了重入。第 07 轮配置将观测位置差容差明确设为 20 mm（包含标定验证最大 10.19 mm 和两视角标签曲面/深度偏差），并把配置 schema 上限扩至 20 mm；默认值仍为 8 mm。位置连续性、目标身份、实际 TCP 到位和 38 mm 预抓取距离审核继续共同生效。该调整不构成对目标真正移动的精确测量。

第 07 轮预抓取终点测距仍为 40.54 mm，未进入重入审核。第 08 轮候选在第一次接近后追加“新点云提案 → 最多 60 步预抓取审核 → 实测执行”，用腕部当前观测校正目标附近的位置，再接回 VLA。第 08 轮使用原 15 mm 位置差容差；最后审核比较最新腕部提案与腕部当前观测。

`wrist-quality-replay.json` 为第 05 轮的离线回归：新版深度覆盖检查下缺观测为零，22 个样本采用右腕；它没有发送机械臂命令，也不是新的任务成功证据。

## 验证与结论边界

相关 gateway、bundle 执行、真机 backend、RGB-D、重入和恢复测试通过 120 项，1 项因本地未安装 RealSense SDK 跳过；实际 dodo 留存毫米深度样本用于在线实验与回归。`git diff --check` 通过。

这个 bundle 是人为构造的 commissioning 候选，用于验证观测和执行接口，未通过演化晋级。实际使用 `tube_geometry`，不声称已经完成 GraspGen 对 ARX 夹爪的真机抓取验证或 VLA 训练。任务成功仍要求：确认粉色目标、夹持及共运动证据，抬升至少 1 cm 并保持五个不同的新帧。
